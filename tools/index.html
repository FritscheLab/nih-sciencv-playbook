SciENcv CPOS XML Validator + Normalizer Upload Template

This tool validates and optionally normalizes SciENcv CPOS XML files using the simple upload template (bare <profile>, no namespaces). It runs checks that commonly explain why XML that "looks fine" still fails SciENcv upload: element order, missing required fields, invalid dates/years, invalid integers, and character-length limits.

Your data is processed entirely in your browser. No files are uploaded to any server.

4) Length limits reference CPOS upload limits

These are the limits this validator enforces for CPOS upload fields.

Element Max length Notes
awardamount 13 digits Digits only (integer). Blank allowed.
awardnumber 50 chars If too long and not safely reducible, leave blank.
supportsource 60 chars Often fails; abbreviate and remove filler.
location 60 chars Primary place of performance.
projecttitle 300 chars Awards only; in-kind typically blank.
inkinddescription 500 chars Required narrative home for in-kind details.
overallobjectives 1500 chars Truncate if needed.
potentialoverlap 5000 chars Usually not binding.
