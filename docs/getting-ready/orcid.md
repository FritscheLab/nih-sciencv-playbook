# ORCID setup (required link + recommended linked account)

**Required for NIH Common Forms:** link your **ORCID iD to your eRA Commons Personal Profile** so it can be used as the Persistent Identifier (PID).

**Strongly recommended for easier setup/import:** link ORCID in **MyNCBI → Account Settings → Linked Accounts** if you want to use ORCID-linked workflows in SciENcv.

{: .note }
> Missing the **eRA Commons** link can create NIH/eRA compliance problems. Missing the **MyNCBI linked account** is usually a workflow problem (more manual entry or limited import options), not the core NIH identity requirement.

## Steps (PI does this)

1. Create ORCID: <https://orcid.org/register>
2. In **eRA Commons**: **Personal Profile → ORCID ID** → connect (**required**)
3. In **MyNCBI**: **Account Settings → Linked Accounts** → add ORCID (**recommended when using ORCID import / linked-account workflows**)
4. In **SciENcv**, confirm your ORCID appears as the **Persistent Identifier (PID)**.
