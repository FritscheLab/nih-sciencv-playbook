- [NIH Loan Repayment Programs hub](https://grants.nih.gov/funding/funding-categories/lrp)

- [NOT-OD-26-082 (2026 Extramural LRP for Pediatric Research)](https://grants.nih.gov/grants/guide/notice-files/NOT-OD-26-082.html)
- [NOT-OD-26-083 (2026 Extramural LRP-FOCUS)](https://grants.nih.gov/grants/guide/notice-files/NOT-OD-26-083.html)
- [FY2027 Extramural LRP Application Instruction Guide](https://grants.nih.gov/sites/default/files/Extramural-LRP-Application-Instruction-Guide.pdf)

The FY2027 LRP workflow requires a digitally certified combined biosketch for the applicant and, when applicable, the primary mentor. A mentored applicant may also upload one optional additional combined biosketch for a mentoring-team member, co-mentor, or key recommender. These program-specific ASSIST instructions do not create a general Common Forms rule for every NIH mechanism.
